# 天枢 Agent 产品能力补齐

基线：`f27a1bfe03140e918cdcaa249d3c5c0863638d28`。本计划描述交付目标，不代表已经实现或已通过 CI。

1. **桌面任务能力。** `WelcomeComposer` 显示本次任务明确声明的出网源、MCP 服务和委派额度。`task.create` 严格转发给 `TaskStore`；旧请求默认无能力。权限仍由 Dispatcher 在执行时判断。测试：RPC 入库、非法输入、桌面提交链和既有拒绝路径。
2. **会话。** 保留 Task/Run 区分。新 Run 以显式选中的同任务历史为输入；从完整的已提交助手正文重建有角色的上下文，不把历史模型调用或审批迁移成新授权。运行中的指导在安全点进入本 Run；开始替代 Run 则是明确的独立动作。澄清问题有用户答复再继续的路径。通用提示按新版本冻结，历史重放仍保留原提示。测试：跨 Run 回复、重建、重复输入、权限、运行中变更及恢复。
3. **联网和连接器。** 先补桌面入口与原生受控搜索，再扩展浏览器与远程 MCP。联网动作保留现有外发审批和 Receipt；浏览器由用户控制可访问的会话和操作范围，不能靠通用工具跳过目标绑定。测试使用本地夹具与伪服务端。
4. **文件输入和交付。** 产物列表从本次 Run 的持久化证据索引，预览按绑定和内容哈希读取有界文本。附件由用户选择并上传，持久化内容引用；图片只交给明示支持的模型，重建时不依赖上传前的源路径。测试：路径、哈希、边界、重放及桌面交付。
5. **计划与压缩。** 优先复用 #207/#208 的工作，不复制计划确认、手动压缩和证据。补未覆盖的计划编辑与澄清等能力；Responses 压缩必须明确保存新边界，不能把不同模型的密文续接混用。
6. **触发。** 固定间隔继续可用；补带时区和星期约束的日历，以及受控本地文件到达触发，外部事件要有独立可信入口、去重和事务化入队。测试注入时钟，覆盖重启和重复触发。
7. **模型配置。** 保存无密钥的模型档案，Run 固定所选配置和估价身份。显式记录备用候选；只有明确没有提交/没有派发的准入阶段可自动替换，已开始的模型调用和 Responses 续接保持身份。测试：跨重启、配置变更和失败边界。

涉及 C1–C5 的契约先以独立 `docs(contract):` PR 固化，再进入代码 PR。授权、事件、网络等 Tier 1 变更需要实测负控、完整本地门禁及绑定代码树的独立复审；桌面改动同步构建 `ui/dist`。当前各切片不修改 `main`、CI 门禁或发行配置。
