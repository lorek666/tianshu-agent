共享预算对象，导致即使设置摘要模式也无法启用；现与产品装配一致地传入该对象。
这也使离线委派任务原先缺失 usage 的预占开始正确累计。`RU-D1` 升为 `1.0.1`，

模型用量，旧版本的任务分母不可直接比较。
新表受不可覆盖/删除触发器保护，也拒绝 `INSERT OR REPLACE` 覆盖。
备份使用既有 SQLite 一致副本，GC 继续只清理其封闭允许集。

独立复审发现并补齐两处负控：读取时重算摘要内容寻址身份并拒绝非法状态；
遥测写入失败不能中断实际用量结算。发送前写入失败不发请求、释放本次预占，
返回后写入失败保留实际消耗、结案失败并回落，缓存回执缺口继续保持未知。
