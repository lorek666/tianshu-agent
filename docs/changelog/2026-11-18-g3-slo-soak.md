# 2026-11-18 · PRD §10.6 本地运行质量冻结 SLO 套件与常驻浸泡框架（G3-B10 / G3-B11）

## 变更背景

PRD §10.6 与 §11.1 G3 发布门禁要求本地运行指标必须形成版本化冻结阈值、覆盖慢订阅者背压与崩溃恢复不变量，并提供可连续运行 ≥10 小时且实时落盘检查点的常驻浸泡工具，同时严格禁止无版本升级的事后放宽与伪造长跑数据。

## 交付内容（纯增量，零侵入核心模块）

1. **版本化契约与冻结阈值（[schemas/slo/slo-v1.json](../../schemas/slo/slo-v1.json)、[schemas/slo/slo-thresholds-v1.json](../../schemas/slo/slo-thresholds-v1.json)）**：
   - 采用项目既有的 JSON Schema 2020-12 封闭关键字子集定义 `thresholdsConfig`、`sloReport`、`soakSample`、`soakReport` 四类结构，直接由 `tianshu.event_schema` fail-closed 校验；
   - 基于本机 `Apple M4 (macOS arm64)` `N=10` 实测基线并计入跨平台 CI 调度余量，冻结 `startup_cold_ms`、`startup_warm_ms`、`cancel_ack_ms`、`cancel_stop_dispatch_ms`、`approval_rpc_ms`、`restart_recovery_ms` 六项指标阈值与常驻浸泡资源上界。
2. **自动化 SLO 基准测量与门禁 CLI（[scripts/measure_slo.py](../../scripts/measure_slo.py)）**：
   - Suite 1：空库冷启动 vs 50 任务 / ≥500 事件种子库热启动真实 `Host` + `Daemon` 子进程可用耗时；
   - Suite 2：真实不读 IPC + Host SSE 慢订阅者填满发送通道下，慢模型与慢工具场景的 `cancel_ack_ms`、`cancel_stop_dispatch_ms`、`approval_rpc_ms`，单独列账已在途副作用并验证 `since_seq` 游标连续补读；
   - Suite 3：4 类真实 `os._exit(77)` 故障点重启 `Daemon` 测量 `restart_recovery_ms`，机械核验 `0` 盲目重试、`0` 丢失回执、`0` 泄漏或清零未决预算预占；
   - 内置防未升版放宽检查（`threshold_relaxed_without_version_bump` → 退出码 `2`）与 D7 路径脱敏。
3. **≥10 小时常驻浸泡运行器（[scripts/run_soak.py](../../scripts/run_soak.py)）**：
   - 默认支持 `10.0` 小时连续运行（`--duration-hours` / `--duration-seconds`）与每 `30s` 实时追加 `samples.jsonl` + 原子刷新 `status.json`；
   - 混合覆盖空闲/活跃采样、`effects`（含文件写改与 F11 `undo`、W4 流式增量）、`pure_only`、F10 记忆、慢订阅者断连与游标重连、中途 `pause`/`resume`/`cancel`、W5 定时调度触发及周期性 `Host`/`Daemon` 优雅重启，结束时严查 RSS 斜率/净增、打开 FD/句柄数、磁盘增长与孤儿进程残留。
4. **回归与负控测试（[tests/test_slo_and_soak.py](../../tests/test_slo_and_soak.py)）与实测基线档案（[docs/SLO-BASELINE-2026-11-18.md](../SLO-BASELINE-2026-11-18.md)）**。

## 已知边界

- 已完成本机 `N=10` SLO 正式门禁实测与 `15s` / `6s` 多周期真实子进程浸泡验证；完整 10 小时墙钟过夜挂机产物未伪造，留待正式发版候选执行归档。
