# 2026-11-19 · W15 按文件身份保护引用材料

[#198](https://github.com/lorek666/tianshu-agent/pull/198) 集成候选曾仅以相对路径拼写匹配引用。不区分大小写的文件系统允许事件读取使用原拼写，目录枚举却可返回同一个文件的另一种拼写。只读计划因此可能错误地将有效材料列为孤儿。

`collect_references()` 在校验单链接、内容哈希和登记大小时验证原生文件身份。保护索引保留登记路径，并识别同一文件的其他拼写。GC 在筛选孤儿、筛选空快照和写前持句柄预检时使用同一判断。已有 SHA256、准入锁以及 Windows 对含文件候选整批拒绝的规则继续适用。

[只读回归](../../tests/test_backup.py) 使用真实 EventLog 和临时卷上的事件外置材料。本机红测显示有效材料被列入候选，修正后只列真实孤儿。用例在区分大小写的卷上检查另一拼写对应的独立文件仍可进入候选，也会确认计划本身未修改文件。提交和平台验收状态见集成 PR。
