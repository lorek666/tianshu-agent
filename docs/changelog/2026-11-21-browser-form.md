# 2026-11-21 · 受限网页表单提交候选

`browser.navigate` 会在适用的公开 HTTPS 页面列出支持提交的静态表单。`browser.submit` 使用同一 Run 记录的来源调用和表单序号，要求逐次批准；审批显示目标和完整值，不携带 Cookie 或授权头。接收方的完整 HTTP 确认会生成可离线核对的网络 Receipt；这只表示请求得到确认。收不到完整确认时会保留未知状态，重启不会自动再提交。

响应头必须以实际空行结束。对端在 `204` 状态行后断开，或在零长度 `201` 的头部尚未结束时断开，都按 `unknown` 记录，不生成 Receipt。回环 TCP 和真实 TLS 的负控均复现了旧实现误记确认；修复后对端仍只收到一次 POST。

实现和验证限于[受限表单契约](../agent-browser-form-contract.md)定义的子集：文本字段，无网页脚本、登录态或文件上传。实际 TLS 验证通过本地测试证书与证书名称负控完成；未对真实站点提交资料。
